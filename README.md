# Salzburg → Trieste flyover

3D flyover of a 9-day Alpe-Adria bike trip (6–15 Sept 2026, ~481 km), built from Garmin GPS tracks.

**Watch it:** https://kaantheyayla.github.io/alpe-adria-flyover/

Press ▶ or Space to fly the route. Click a day or the elevation profile to jump.
